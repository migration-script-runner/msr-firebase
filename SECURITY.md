# Security Policy

## Supported versions

Security fixes are provided for the latest published release. Older releases are not maintained. See [GitHub Releases](https://github.com/migration-script-runner/msr-firebase/releases) for published versions.

## Report a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, pull request, or discussion.

If private vulnerability reporting is enabled, use [GitHub's private vulnerability reporting form](https://github.com/migration-script-runner/msr-firebase/security/advisories/new). If the form is unavailable, open a GitHub issue asking for a private reporting route, without including vulnerability details or sensitive information. Do not send vulnerability reports to personal email addresses.

Include the affected version, impact, and steps to reproduce in the private report. Please allow maintainers time to investigate and coordinate a fix before public disclosure.
